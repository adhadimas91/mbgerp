# Module 11: ISO Compliance & Quality Assurance

## 1. Objectives
Memastikan sistem ERP mendukung kepatuhan terhadap standar industri pangan, mutu, dan keamanan informasi yang diperlukan untuk program MBG.

## 2. Key Standards Supported

### ISO 22000 / HACCP (Food Safety Management)
- **Traceability**: Pelacakan bahan baku dari supplier ke titik distribusi (Lot tracking).
- **Temperature Logs**: Pencatatan suhu gudang dan transportasi (Cold Chain).
- **Supplier Audits**: Penilaian rutin terhadap kebersihan dan keamanan pangan supplier.

### ISO 9001 (Quality Management)
- **Standard Operating Procedures (SOP)**: Dokumentasi alur kerja dalam sistem.
- **Corrective Actions**: Pencatatan insiden (misal: bahan makanan rusak) dan langkah perbaikannya.
- **Performance Metrics**: KPI untuk setiap titik distribusi dan supplier.

### ISO 27001 (Information Security)
- **Audit Trails**: Pencatatan semua aktivitas user (Sudah diimplementasikan di Module 7).
- **Role-Based Access Control (RBAC)**: Pembatasan akses data sensitif berdasarkan peran.
- **Data Encryption**: Enkripsi data sensitif (password, data pribadi, transaksi keuangan).

## 3. Features
- **Certification Management**: Dashboard untuk memantau masa berlaku sertifikasi ISO/Halal dari semua supplier dan fasilitas.
- **Compliance Dashboard**: Monitoring status kepatuhan di seluruh wilayah.
- **Incident Reporting**: Modul untuk melaporkan masalah keamanan pangan atau ketidaksesuaian mutu di lapangan.
