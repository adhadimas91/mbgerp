# Module 6: Dashboard & Reporting

## 1. Objectives
Menyediakan visualisasi data untuk pengambilan keputusan cepat oleh manajemen.

## 2. Features
### Real-time KPI Dashboard
- Total porsi terdistribusi hari ini.
- Persentase pemenuhan stok bahan baku.
- Grafik tren pengeluaran vs anggaran.

### Reporting System
- Laporan distribusi harian (PDF/Excel).
- Laporan stok bulanan.
- Laporan akuntabilitas keuangan untuk audit.

## 3. Key Components
- **Map View:** Visualisasi titik distribusi dan status pengiriman (Live Map).
- **Charts:** Line chart untuk tren biaya, Pie chart untuk komposisi nutrisi.
- **Filters:** Filter berdasarkan wilayah, periode waktu, dan jenis modul.
