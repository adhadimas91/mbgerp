# Tech Stack & Infrastructure

## 1. Frontend
- **Framework:** Next.js (React) - Untuk SEO, performa, dan routing yang efisien.
- **Styling:** Tailwind CSS + Shadcn UI - Untuk UI yang konsisten dan cepat dikembangkan.
- **State Management:** TanStack Query (React Query) - Untuk manajemen data fetching.

## 2. Backend
- **Framework:** NestJS (Node.js) - Arsitektur modular yang mendukung skalabilitas enterprise.
- **Language:** TypeScript - Untuk keamanan tipe data.
- **ORM:** Prisma - Untuk interaksi database yang aman dan efisien.
- **Validation:** Class-validator & Zod.

## 3. Database
- **Primary Database:** PostgreSQL - Relational data yang kuat untuk keuangan dan stok.

## 4. Deployment & Monitoring
- **Cloud Provider:** AWS atau Google Cloud Platform.
- **CI/CD:** GitHub Actions.
- **Monitoring:** Prometheus & Grafana.
